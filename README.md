# St. Jude High School - Inventory Management System

A functional, secure, and complete web-based inventory, procurement, and fixed-asset management prototype designed specifically for high schools.

Built with **Core PHP**, **MySQL**, **Bootstrap 5**, **HTML5/CSS3**, and **JavaScript/jQuery** using **PDO prepared statements** for database operations.

---

## Key Modules & Phased Implementation Roadmap

| Phase | Module Name | Scope & Status |
| :--- | :--- | :--- |
| **Phase 1** | **Foundation, Auth & RBAC** | **Implemented**: Complete database schema, PDO singleton, secure session cookies, BCrypt password hashing, brute-force rate limiting, CSRF protection, shared navigation layouts, role-based views, and XAMPP documentation. |
| **Phase 2** | **Inventory & Categories** | **Implemented**: Item creation, editing, keyword search, categories management, standard school units, storage locations, consumable vs fixed-asset classification, opening stock recording, minimum stock thresholds, atomic stock movements, live dashboard statistics, and low-stock alerts. |
| **Phase 3** | **Procurement & Receiving** | Supplier management, Purchase Orders (PO), and Goods Received Notes (GRN). *Stock increases strictly upon GRN generation.* |
| **Phase 4** | **Requisitions & Issuing** | Department stock requisitions and HOD approvals. *Approval does NOT reduce stock; stock decreases strictly upon physical stock issue.* |
| **Phase 5** | **Fixed Asset Register** | Individual asset tagging and tracking (Computers, Science lab apparatus, furniture, school vehicles). |
| **Phase 6** | **Movements & Analytics** | Stock movement ledger, returns, damage reporting, Chart.js live analytics, and system audit trail. |

## Business Rules & Constraints

1. **Fixed Currency (KSh):** Currency is strictly set to **Kenyan Shillings (KSh)** across all screens and transactions. No currency selection or conversion is implemented.
2. **Dashboard-Only Alerts:** Low-stock alerts appear exclusively on the dashboard when consumable stock is at or below the defined `reorder_level`.
3. **No External Notifications:** No external email or SMS delivery services are integrated; alerts remain localized within the application.
4. **Consumable vs. Fixed Asset Separation:** Consumable items (stationery, laboratory reagents, dry boarding foodstuff) are tracked by quantity-on-hand; fixed assets (computers, microscopes, school buses) are individually tracked with unique asset tags, serial numbers, and condition states.
5. **Stock Flow Integrity:**
   - **Inflow:** Stock quantity increases **only** when goods are physically received and recorded via a Goods Received Note (GRN).
   - **Outflow:** Stock quantity decreases **only** when stock is physically issued via a Stock Issue Note.
   - **Approval Rule:** Approval of a requisition by an HOD or Principal does **not** automatically decrease stock.
6. **Data & Transaction Safety:** All stock-changing operations use atomic database transactions (`beginTransaction`, `commit`, `rollBack`) to prevent duplicate references or inconsistent balances.

## XAMPP Setup Instructions (Windows)

### Step 1: Place the Project in XAMPP
Copy the `schoolinventorymanagement` folder into your XAMPP web root:
```text
C:\xampp\htdocs\schoolinventorymanagement
```

### Step 2: Start Apache and MySQL
1. Launch the **XAMPP Control Panel** (`xampp-control.exe`).
2. Click **Start** for **Apache**.
3. Click **Start** for **MySQL**.

### Step 3: Create and Seed the Database
You can set up the database in **either** of two ways:

#### Option A: Using phpMyAdmin (Recommended)
1. Open your browser and go to: `http://localhost/phpmyadmin/`
2. Click **New** in the left sidebar and name the database `school_inventory` with collation `utf8mb4_unicode_ci`.
3. Select the `school_inventory` database.
4. Click the **Import** tab.
5. Click **Choose File** and select `C:\xampp\htdocs\schoolinventorymanagement\database\schema.sql`. Click **Go**.
6. Click the **Import** tab again, select `database\seed.sql`, and click **Go**.

#### Option B: Using the Built-in Web Setup Utility
1. Navigate to `http://localhost/schoolinventorymanagement/setup_database.php` in your browser.
2. Click **Execute Full Setup (Schema + Seed Data)**.

### Step 4: Run the Application
Access the application at:
```text
http://localhost/schoolinventorymanagement/
```
Log in using any of the default development credentials (e.g., `admin` / `Admin@123` or `storekeeper` / `Store@123`).

## Security Verification & Hardening

1. **Prepared Statements (PDO):** Every query uses parameterized inputs with `PDO::ATTR_EMULATE_PREPARES => false`. User inputs are never directly concatenated into SQL.
2. **Context-Aware Escaping:** All user-controlled text rendered into HTML templates passes through `e()`, which calls `htmlspecialchars($str, ENT_QUOTES, 'UTF-8')`.
3. **Session Security:**
   - Inactivity timeout: 30 minutes.
   - `session.use_strict_mode = 1`, `session.use_only_cookies = 1`.
   - Cookies configured with `HttpOnly` and `SameSite=Lax`.
   - `session_regenerate_id(true)` executed upon successful authentication to eliminate session fixation.
4. **CSRF Protection:** Synchronizer tokens generated via `random_bytes(32)` validated on all state-changing `POST` requests.
5. **Brute-Force Rate Limiting:** Consecutive failed login attempts are tracked in the `login_attempts` table, automatically locking out an IP/username after 5 failed tries within a 15-minute window.
